# Real-Time Collaborative Whiteboard

A real-time collaborative whiteboard built using **Node.js, Express.js, HTML Canvas, EJS, and WebSocket**.

The application allows an administrator to draw on a digital canvas and synchronize drawing actions with connected clients in real time.

## Features

- Real-time drawing using WebSocket
- HTML5 Canvas-based whiteboard
- Multiple colors
- Adjustable brush width
- Eraser
- Undo and Redo
- Clear canvas
- Admin and Client interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- WebSocket (`ws`)
- EJS
